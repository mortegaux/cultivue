# Security Policy

## Reporting Security Vulnerabilities

We take the security of CultiVue seriously. If you discover a security vulnerability, please do **not** open a public issue.

Instead, please report the vulnerability privately via:
* **GitHub Private Vulnerability Reporting:** Navigate to the repository's **Security** tab and click **Report a vulnerability**.
* Or contact the repository maintainer directly.

Please include:
* Description of the vulnerability
* Steps to reproduce or proof-of-concept
* Potential impact

We will investigate and work on a fix promptly.
